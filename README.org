#+title: customize-agents

Everything that customizes my coding agents (Claude Code, Pi, Codex), in one place, shared by all of them.  Planning documents live elsewhere, in =~/Stillness/Agent_Stuffs/Plans=.

* Layout

| Path                    | What                                                              |
|-------------------------+-------------------------------------------------------------------|
| =skills/=               | Agent skills; =install.sh= links each one into every harness.    |
| =skills/explore-session/= | Spin a tangent off into a child session in a new tmux window (brief by default, fork on request) and bring a short summary back; shared scripts, plus =extensions/pi/explore-session.ts= for Pi. |
| =emacs/agent-sessions/= | Emacs dashboard for agent sessions, its hook scripts and =bin/= commands. |
| =emacs/test-bed/=       | Isolated Emacs for trying agent-sessions (=--init-directory=).   |
| =extensions/pi/=        | Pi extensions.                                                     |
| =hooks/=                | Harness hook scripts.                                              |
| =instructions/<agent>/= | Global instructions per agent (Pi =AGENTS.md=, Claude =CLAUDE.md=). |
| =settings/<agent>/=     | Agent settings (=settings.json=; Claude's =statusline.sh=).        |
| =commands/<agent>/=     | Slash commands (Claude).                                            |
| =prompts/<agent>/=      | Prompt templates.                                                   |

* Install

#+begin_src sh
./install.sh
#+end_src

Links every =skills/<name>= into =~/.claude/skills=, =~/.agents/skills= and =~/.config/pi/skills= (Pi's home, =PI_CODING_AGENT_DIR=).  It never overwrites a real directory; those are reported instead.

Pi's home is =~/.pi/agent= (its own data: sessions, auth, trust, caches).  Its =AGENTS.md=, =settings.json=, =prompts= and =extensions= there are one-hop links into this repo.  Likewise Claude's home is =~/.claude=; its =CLAUDE.md=, =settings.json=, =statusline.sh= and =commands= are one-hop links here, and =settings.local.json= stays local.

The Emacs config loads =emacs/agent-sessions= from this path (=load-path=); see =~/.emacs.d/modules/personal/ai-sessions-config.el=.  Agents run as tmux windows (=agent-sessions-tmux.el=).
